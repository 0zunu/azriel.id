Git adalah sistem perangkat lunak kontrol versi terdistribusi yang mampu mengelola versi dari kode sumber atau data. Ini sering digunakan untuk mengontrol kode sumber oleh para programmer yang mengembangkan perangkat lunak secara kolaboratif. Awalnya, Git dibuat oleh Linus Torvalds untuk kontrol versi dalam pengembangan kernel Linux.
